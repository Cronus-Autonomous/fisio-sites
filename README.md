# Clínica Shoyufisio Branding

CRIAÇÃO DE LANDING PAGE PREMIUM — Clínica Shoyufisio

Crie uma landing page profissional, elegante, moderna, responsiva e orientada à conversão para o Clínica Shoyufisio, localizado em Londrina — PR.

O negócio atua com Fisioterapia Manual, Hidroterapiae Home Care e Pilates, oferecendo tratamentos personalizados para dor, tensão muscular, mobilidade, drenagem linfática, lipedema e recuperação pós-operatória.

A página deve transmitir imediatamente:

confiança;

acolhimento;

profissionalismo;

cuidado individualizado;

sofisticação;

bem-estar;

autoridade técnica;

sensação de atendimento personalizado.

O principal objetivo da página é converter visitantes em agendamentos pelo WhatsApp.

A página final deve parecer um projeto profissional desenvolvido por uma agência premium de branding e UX/UI para uma clínica de saúde e bem-estar.

3. DIREÇÃO DE DESIGN

O design deve combinar:

Luxury Wellness + Healthcare Premium + Human Care.

Evitar aparência excessivamente hospitalar.

Evitar também estética genérica de salão de beleza.

A percepção desejada é:

"Um espaço especializado onde vou ser cuidado por uma profissional que entende meu corpo e vai olhar para minha necessidade individual."

Use:

bordas arredondadas moderadas;

cards elegantes;

sombras muito suaves;

tipografia sofisticada;

grandes áreas de respiro;

imagens com cantos arredondados;

composição editorial;

elementos orgânicos discretos;

linhas e formas curvas inspiradas em movimento corporal.

Não utilizar:

gradientes exagerados;

excesso de sombras;

efeitos neon;

glassmorphism excessivo;

animações chamativas;

excesso de elementos decorativos;

aparência de template genérico.

4. TIPOGRAFIA

Utilize uma combinação tipográfica premium e extremamente legível.

Sugestão:

Headings: Playfair Display ou uma serif elegante semelhante.

Body/UI: Inter, Manrope ou DM Sans.

A tipografia deve criar contraste entre:

sofisticação + modernidade + legibilidade.

Headlines podem utilizar serif elegante, enquanto botões, menus, descrições e informações práticas devem utilizar uma sans-serif moderna.

23. ANIMAÇÕES E MICROINTERAÇÕES

Utilizar animações minimalistas.

A experiência deve parecer sofisticada, não "animada demais".

Implementar:

slide-up extremamente sutil;

parallax muito leve nas imagens principais;

hover suave nos cards;

pequenas transições nos botões;

underline animado no menu;

transformação de 1–2px nos cards ao passar o mouse;

scale extremamente discreto em imagens;

transição suave do header ao fazer scroll.

Usar preferencialmente:

Framer Motion

ou biblioteca equivalente já compatível com o projeto.

Duração média:

300–700ms

Utilizar easing suave.

Respeitar:

prefers-reduced-motion

para usuários que optarem por reduzir animações.

A página deve ter excelente equilíbrio entre estética e conversão.

Use a referência visual enviada como inspiração de estrutura, mas desenvolva uma identidade própria para o Clínica Shoyufisio utilizando a paleta definida.

Entregue uma interface visualmente refinada, responsiva, acessível, rápida e pronta para receber os dados reais de WhatsApp, Google Meu Negócio, Instagram e imagens do estabelecimento posteriormente.
